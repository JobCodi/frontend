# JobCodi 맞춤 공고 탐색 홈 디자인

## 목표

방문자가 JobCodi를 단순한 안내 페이지가 아닌, AI 대화로 조건을 정리하고 여러 출처의 공고를 모아주는 **맞춤 공고 탐색 서비스**로 즉시 이해하고 시작하도록 한다.

## 레퍼런스 해석

- **Wanted Montage**: 한 가지 주조색, 명확한 타이포 위계, 표면·테두리·반경 토큰을 일관되게 사용한다.
- **자소설닷컴**: 검색 진입과 직무 카테고리 탐색을 빠르게 제공한다.
- **사람인·잡코리아**: 공고 카드에 회사·직무·근무형태·마감·출처 등 신뢰를 만드는 정보를 계층적으로 배치한다.
- JobCodi는 외부 사이트의 브랜드·카피·자산을 복제하지 않고, AI 기반의 개인 조건 정리와 수집이라는 제품 차별점에 집중한다.

## 화면 구조

1. **히어로**: 작은 서비스 라벨, “내 조건에 맞는 공고부터” 메시지, AI 대화 시작 CTA, 보조 소개 링크를 둔다.
2. **탐색 프리뷰**: 우측(모바일은 하단)에 3단계 조건 카드와 매칭 결과 요약을 배치해 시작 이후의 결과를 구체화한다.
3. **빠른 탐색**: 직무 키워드를 실제 버튼형 칩으로 제공한다. 현재는 `/start`로 일관되게 이동하며 특정 조건을 서버에 저장하지 않는다.
4. **맞춤 공고 미리보기**: 정적 예시 카드 3개로 매칭 점수, 근거, 고용형태, 마감 정보를 보여 준다. 실제 API 데이터로 오해하지 않도록 `예시 미리보기`를 명시한다.
5. **신뢰/프로세스**: 고용24·사람인·기업 채용 페이지 등 실제 출처를 밝히고, 5문답 → 조건 확인 → 공고 수집의 과정을 짧게 표현한다.
6. **푸터**: 출처 및 서비스 소개 링크를 유지한다.

## 시각 규칙

- 기존 보라색 브랜드 토큰을 주조색으로만 사용한다. 성공·주의 상태 색은 의미가 있는 소수 항목에 한정한다.
- 카드 반경은 `--radius`, 테두리는 `--line`, 그림자는 `--shadow-card`로 통일한다.
- 기본 컨테이너는 `max-w-6xl`; 히어로는 데스크톱 2열, 모바일 1열이다.
- 카드의 점수에는 텍스트 근거를 함께 제공하며, 색만으로 상태를 구분하지 않는다.
- 장식 아이콘은 Lucide의 단일 stroke 언어를 사용하고 `aria-hidden`으로 처리한다.

## 접근성·반응형

- 탐색 칩과 CTA는 모두 실제 링크/버튼이며 명확한 목적지를 갖는다.
- 정보 카드와 목록은 시맨틱 heading/list 마크업을 사용한다.
- 640px 미만에서는 히어로 프리뷰, 공고 카드, 과정 카드가 한 열로 전환된다.
- 커스텀 애니메이션을 추가하지 않아 reduced-motion 규칙을 확장하지 않는다.

## 검증 기준

- 모바일과 데스크톱에서 CTA·탐색·공고 미리보기가 깨지지 않는다.
- `pnpm lint`, `pnpm typecheck`, `pnpm build`가 성공한다.
- 로컬 브라우저 QA에서 `/`의 CTA와 홈/소개 링크가 정상 탐색된다.
