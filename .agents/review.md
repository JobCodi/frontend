# 프런트엔드 리뷰 프로필

다음 순서로 변경을 검토한다.

1. `/start` → 대화 → 조건 확인 → 피드의 정상·새로고침·뒤로 가기·세션 복원 흐름을 확인한다.
2. `params` await, Server/Client Component 경계, Query·Zustand·URL 상태 소유권을 확인한다.
3. POST 재시도 금지, collecting 폴링 종료, 오류·세션 만료 처리를 확인한다.
4. `score`·`rank`·`reasons`의 서버 정본과 공고 본문 비노출을 확인한다.
5. 접근성 라벨, 키보드 흐름, 로딩·오류 안내와 작은 화면 레이아웃을 확인한다.

발견 사항은 심각도, 파일·위치, 사용자 영향, 재현 또는 근거를 함께 기록한다. 문제가 없으면 실행한 검증과 확인한 사용자 흐름을 남긴다.
